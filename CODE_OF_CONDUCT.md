# Code of conduct

## Our standard

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which is linked rather than reproduced so that it cannot drift from the text it
claims to be.

In short: participate in a way that would make someone new to this repository
willing to ask a question in public.

## What this means here specifically

Most of this repository's discussion is about whether something is **true** —
whether a gate checks what it says, whether a document matches the filesystem,
whether a number was measured or assumed. That kind of review is direct by
necessity, and directness about the work is welcome.

Directness about a person is not. "This gate passes without checking anything"
is the review this project wants. "You do not know what you are doing" is not,
and it is also less useful, because it names nothing anyone can fix.

Being wrong is normal here. Several of this repository's better mechanisms
exist because a mistake was found and written down — the commit history says so
explicitly, on purpose. Nobody is expected to arrive correct.

## Enforcement

Report unacceptable behaviour to `DuqueOrtegaMutis@gmail.com`. Reports are
handled privately and the reporter's identity is not shared without consent.

Consequences follow the Contributor Covenant's enforcement ladder: a private
correction first, then a warning, then a temporary or permanent ban, depending
on severity and repetition.

## Scope

This applies in the repository — issues, pull requests, discussions, commit
messages — and anywhere someone is representing the project.
