# agent-local v0.7.0 — AUDIT R9 enterprise-benchmark remediation

**Date**: 2026-07-02 · **Line**: pre-1.0 · **Upstream benchmark**:
template_MLOps `docs/audit/ACTION_PLAN_R9_ENTERPRISE_BENCHMARK.md` (Wave B)

The R9 benchmark compared this platform against the industry's dominant
agentic frameworks (LangGraph, OpenAI Agents SDK, Google ADK, CrewAI) and
against the evaluation frameworks a security/compliance reviewer actually
uses (OWASP LLM Top 10). Verdict: the architecture's core bet — a
deterministic policy gate no LLM can talk its way past, fail-closed tools,
budget-bounded execution — has no equivalent combination in any reference
framework. The gaps found were all legibility and process, not design, and
this release closes every one of them.

## Highlights

- **Six tags, zero GitHub Releases — fixed, and fixed structurally**
  (R9-06): `v0.1.0`–`v0.6.0` are now real GitHub Releases with real
  history. A new `release-on-tag.yml` and a `check_coherence.py` C5 check
  (tag/release parity, CI-enforced) mean this specific class of bug cannot
  recur silently.
- **The threat model is now written down** (`docs/SECURITY_MODEL.md`,
  R9-07): every OWASP LLM Top-10 (2025) category mapped to this platform's
  actual controls, with two categories honestly marked unmitigated rather
  than glossed over.
- **The MCP question has an answer, in writing** (ADR-010): rejected, with
  the precise technical reason (annotation-trust vs. ADR-006's fail-closed
  contract) and the exact conditions that would reopen it.
- **Adversarial coverage exists now** (R9-08): 15 injection-flavored eval
  cases (including two honestly-documented keyword-evasion gaps in the
  policy engine) plus 6 full-loop containment tests proving the policy
  gate holds even when the model itself has been successfully fooled —
  not just when the gate is unit-tested in isolation.
- **CI Actions SHA-pinned**, coverage reported (not yet gated, with a
  written policy for why and when that changes).
